# Security and Safety

## Scope
ASIB is an Earth-based research and simulation testbed. It must not be connected to live spacecraft, launch systems, satellite command links, physical actuators, propulsion systems, or safety-critical mission control.

## Reporting
For suspected software vulnerabilities, open a GitHub issue with the smallest reproducible example that does not expose credentials, private infrastructure details, or operational command material.

## Safety boundary
The hardware-in-the-loop layer is intentionally simulation-only. Any future physical integration requires independent safety engineering, interface qualification, authorization controls, fault containment, and verification outside this repository.
